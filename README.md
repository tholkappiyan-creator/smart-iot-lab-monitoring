# Smart IoT Lab Monitoring System - V2

🚀 **Live Demo:** https://smart-iot-lab-monitoring-ekgrnmjrg76zs7l5vtqp8n.streamlit.app/

Smart IoT Lab Monitoring System using Python Streamlit.

### Features:
* Live Temperature, Humidity, Gas & Light Monitoring
* Gas Leakage Detection with RED ALERT
* Buzzer Alarm System - BEEP... BEEP... BEEP...
* Live Sensor Trends Graph - Day 2
* Control Panel - Refresh Speed & Gas Alert Limit
* Real-time Sensor History Table
* Simple & Clean Dashboard UI

### Technologies Used:
* Python
* Streamlit
* Pandas

### How to Run:
pip install -r requirements.txt
streamlit run app.py
